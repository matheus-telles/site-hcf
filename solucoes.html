Segurança

Home Office Seguro

Trabalho remoto com proteção corporativa, produtividade integrada e visibilidade total dos endpoints.

Combinamos identidade gerenciada do Microsoft 365 com VPN corporativa Fortinet e detecção de ameaças em tempo real via Kaspersky EDR. Resultado: colaboradores acessam dados sensíveis de qualquer lugar com o mesmo nível de controle do escritório, e o time de TI mantém auditoria de acessos, MFA obrigatório e contenção automática de incidentes.

O que está incluso

  • Licenciamento Microsoft 365 Business + configuração de tenant
  • FortiGate SSL-VPN com perfis por grupo de usuário
  • Kaspersky EDR em todos os endpoints com console central
  • Setup, treinamento de equipe e 30 dias de suporte assistido HCF

Cloud

Migração Cloud Híbrida

Sair de data center legado preservando workloads críticos, sem janela de indisponibilidade prolongada.

Mapeamos dependências de aplicação, definimos quais cargas vão para AWS e quais permanecem em VMware Cloud Foundation, e conectamos tudo via Cisco SD-WAN com SLA definido por aplicação. A HCF conduz o assessment, executa o piloto, valida com seu time e só então faz o cutover. Você ganha elasticidade de cloud onde faz sentido e mantém investimento em hardware onde a economia é real.

O que está incluso

  • Assessment Well-Architected e plano de migração faseado
  • Provisionamento AWS (landing zone, redes, IAM, FinOps inicial)
  • Implantação VMware Cloud Foundation on-prem
  • Cisco SD-WAN ligando filiais, DC e cloud com QoS por app
  • Cutover assistido por equipe HCF + handover documentado

Resiliência

Continuidade & DR

Disaster recovery multi-site com RPO/RTO definidos por aplicação e testes regulares de failover.

Construímos camadas de proteção: snapshot local em VMware para recuperação rápida, backup imutável em AWS Backup para resistência a ransomware, e armazenamento IBM em site secundário para retenção de longo prazo. Cada aplicação crítica recebe um runbook documentado com gatilho, sequência de restauração e responsáveis, e a HCF acompanha o primeiro teste real de failover.

O que está incluso

  • Análise BIA: classificação de aplicações por criticidade
  • Replicação VMware com RPO < 15min para Tier 1
  • AWS Backup com cofre imutável e retenção configurável
  • IBM Storage no site secundário para arquivamento
  • Runbooks de DR + simulação de failover guiada pela HCF
VMware AWS Backup IBM Storage Runbook HCF

Modernização

Modernização de Core

Sair de sistemas legados (mainframe, ERP antigo, Power IBM) sem parar a operação.

Abordagem estrangulada: o legado continua rodando enquanto a HCF migra módulo a módulo para Azure ou Dynamics 365, sempre com pareamento de dados e janelas curtas de cutover. Cada onda traz roadmap, plano de rollback e capacitação do time interno. O resultado é um core moderno, integrável com APIs e analytics, sem o trauma de um big-bang.

O que está incluso

  • Discovery do legado + roadmap de modernização por ondas
  • Migração assistida Power → Azure (IaaS, PaaS ou refactor)
  • Implantação Microsoft Dynamics 365 onde aplicável
  • Integração via API entre legado remanescente e novos serviços
  • Capacitação do time interno + handover técnico estruturado
